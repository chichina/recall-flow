# Recall Flow · 知行卡片 Web

中文静态学习卡片界面：导入学习包、翻卡、答题、查看进度和来源，以及导出记录与备份。仓库内只有前端运行文件，首次打开为空状态。

## 本地启动

使用任意静态 HTTP 服务器。在仓库目录可运行 Python 标准库服务器：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:4173/ 。浏览器需要支持 ES Modules；通过 HTTP 打开，不直接使用 file://。页面无需 npm 安装、构建、账号或 API 密钥。所有模块和样式均在仓库内，资源使用相对路径。

## 导入与保存数据

在“导入与导出”中选择或粘贴 `schema_version: "1.0"` 的 JSON：

- `learning_pack`：学习包，包含 `pack_id`、`revision`、`sources`、`concepts`、`decks`、`cards`、`questions`。卡片和题目通过 `source_refs` 关联来源。
- `session`：已完成答题，包含题目版本快照、原答、信心、自评与确定性判分。需要先有对应学习包。
- `assessment`：外部工具对开放题的评价，通过 `attempt_id` 对应已有回答。
- `plan`：按日期与分钟预算安排的学习项目及延后理由，引用已有学习包和答题记录。
- `backup`：完整数据容器，可一次导入学习包、记录、评价、计划与附件。

逐份导入时按学习包 → session → assessment → plan 的顺序。选择题在浏览器按原题快照判分；开放题保留原答并等待导入外部评价。信心和自评不等于正确性。图片附件只保存为待提取资料，页面不执行 OCR 或 AI 请求。

记录保存在当前站点的浏览器 localStorage。答题后点击“结束并保存本次练习”或“导出本次 session”；刷新可继续已提交的草稿。请定期下载“完整数据备份”，跨浏览器或电脑时手动导入。相同记录重复导入不增加副本，同 ID 内容冲突会被拒绝；资料修订保留旧包和历史题目快照。

卡片支持空格翻面及左右方向键切换。Anki 导出为浏览器生成的 UTF-8 TSV；图片需放入 Anki 的 collection.media 根目录，按页面说明设置字段。Web 的历史不作为 Anki FSRS 历史，也不提供双向同步。
